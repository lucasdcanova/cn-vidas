# Pods Directory

Este diretório contém as dependências do CocoaPods para o projeto iOS.

## Importante

- Este diretório é gerenciado automaticamente pelo CocoaPods
- O arquivo `Pods-App.xcconfig` é versionado para garantir builds consistentes no Xcode Cloud
- Execute `pod install` após clonar o repositório ou atualizar dependências

## Comandos úteis

```bash
# Instalar/atualizar pods
pod install

# Atualizar repositório de specs e instalar
pod install --repo-update

# Limpar cache de pods (se necessário)
pod cache clean --all
```
